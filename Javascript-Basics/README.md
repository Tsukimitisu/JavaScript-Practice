# JavaScript basics

Open [index.html](index.html) in a browser to see arithmetic and template-string results rendered as a list.

Read the inline script from the price constants through `exerciseResults` to the `forEach` loop. Each result becomes an `li` using `createElement`, `textContent`, and `append`.

Try changing `shirtPrice` from 10 to 15 and reloading. The shopping total should change from $38 to $43. The balance example starts at $100, spends $70, and adds $200, producing $230.

Practice: add another purchase constant and include it in `shoppingTotal`.
