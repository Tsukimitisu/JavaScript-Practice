# Contributing

Thanks for helping improve these JavaScript exercises.

## Local workflow

1. Create a branch from `main`.
2. Make one focused change at a time.
3. Run `npm test` before committing.
4. Open the changed HTML exercise in a browser when the change affects the UI.

Node.js 18 or newer is required for the built-in test runner. No dependency
installation is needed for the current test suite.

## Commit messages

Use a short, action-oriented subject. Prefixes such as `feat:`, `fix:`,
`test:`, `docs:`, and `chore:` make the project history easier to scan.
