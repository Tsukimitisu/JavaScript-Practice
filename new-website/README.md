# Luma Studio practice site

Open [index.html](index.html) in a browser. [styles.css](styles.css) controls layout and appearance; [script.js](script.js) handles palettes, navigation, and the contact form.

Try cycling through Ember, Evergreen, and Berry, then reload. The selection persists under `palette-index`. Reset Palette restores Ember and clears the saved choice.

At a narrow viewport, open the navigation menu and press Escape. The menu should close and return focus to its toggle. Explore Projects scrolls to the featured work section.

The contact form is a frontend demonstration: it validates an email and displays a message, but has no request to a backend and sends no proposal email. Try an invalid address, then a valid one to inspect both states.
